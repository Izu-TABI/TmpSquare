## インストール

1. 下の **DropShelf.zip** をダウンロードして開き、`DropShelf.app` を「アプリケーション」フォルダに移動します。
2. `DropShelf.app` を開きます。Apple の公証を受けていないため、初回は「開いていません」という警告が出るので「完了」を押します。
3. 「システム設定」→「プライバシーとセキュリティ」を開き、下の方にある DropShelf の「このまま開く」を押します。
4. もう一度確認が出たら「このまま開く」を押します。

メニューバーにトレイのアイコンが出たら準備完了です。ファイルをドラッグしながらカーソルを左右に振るとシェルフが開きます（⌥⇧Space でも開けます）。

ターミナルが使える場合は、手順 2〜4 の代わりに次のコマンドでも開けるようになります。

```
xattr -dr com.apple.quarantine /Applications/DropShelf.app
```

**動作環境**: macOS 14 以降（Apple シリコン / Intel）
